# NewsGauge — Fakeddit Fake-News Classifier (distilbert-base-uncased)

Trained and evaluated on 2026-09-11. Every number below is copied directly from the executed run of
`notebooks/train_final_model.ipynb` — see that notebook for the full, reproducible trail.

## Model description

A `distilbert-base-uncased` model fine-tuned for **binary (2-way) fake-news classification** on post titles
from the [Fakeddit](https://fakeddit.netlify.app/) dataset (Nakamura, Levy & Wang, 2020). Given a short
headline/title, the model predicts whether it resembles a **real** or **fake** Reddit post, along with a
temperature-calibrated confidence score.

**This model classifies headline *style*, not claim veracity.** See Limitations below before using it for
anything beyond a research demo.

## Intended use

- **Intended**: research and educational demonstrations of fake-news-style text classification; a component
  in a larger, human-reviewed content-moderation pipeline; teaching material on BERT fine-tuning, calibration,
  and evaluation methodology.
- **Not intended**: standalone fact-checking of real-world claims, automated content removal without human
  review, or use on text substantially different from short English Reddit-style headlines (e.g. long-form
  articles, non-English text, social media posts with heavy slang/emoji not represented in training).

## Training data

- **Source**: Fakeddit (Nakamura, Levy & Wang, 2020), official `all_train.tsv` / `all_validate.tsv` /
  `all_test_public.tsv` splits, pooled and re-split (see Methodology below).
- **Label**: `2_way_label` (0 = real, 1 = fake), derived by Fakeddit's authors via distant supervision from
  the subreddit each post was collected from — not per-post human fact-checking.
- **Sampling**: balanced to 2,500 examples per class (5,000 total) from the full pooled
  set to keep training fast and classes balanced; this is a small fraction of Fakeddit's 1M+ posts.
- **Split**: 3,500 train / 500 validation / 1,000 test, stratified by label.
  **Note**: because the official Fakeddit train/validate/test files were pooled before re-splitting, these
  numbers are not directly comparable to results reported against Fakeddit's own official test split in
  other papers.

## Methodology

- **Model selection**: `bert-base-uncased` and `distilbert-base-uncased` were both fine-tuned across
  3 seeds each; final choice (distilbert-base-uncased) was based on mean test F1 and a Welch's t-test
  between the two models' per-seed F1 scores (p = 0.4365), not on assumption.
- **Checkpoint selection**: best epoch chosen by validation F1 (not test F1) — the test set was evaluated
  exactly once, after training and checkpoint selection were both complete.
- **Calibration**: post-hoc temperature scaling (Guo et al., 2017, [arXiv:1706.04599](https://arxiv.org/abs/1706.04599)),
  fit on validation logits only. Fitted temperature T = 1.110.
  Test-set Expected Calibration Error: 0.0813 (raw) → 0.0656 (calibrated).
- **Hyperparameters**: max_len=64, batch_size=32, lr=2e-5, epochs=4,
  weight_decay=0.01, warmup_ratio=0.1. See `notebooks/train_final_model.ipynb`
  Section 2 for the exact config used.

## Limitations

- **Not a general-purpose fact-checker.** Labels come from Fakeddit's distant-supervision scheme
  (subreddit of origin), not per-claim human fact-checking. The model learns headline style correlates of
  those labels, which is a different task from verifying whether a specific claim is true.
- **Domain-narrow.** Trained only on short Reddit post titles in English. Performance on news articles,
  tweets, other languages, or claims postdating the training data collection is untested.
- **Small, balanced training sample.** 5,000 examples is a small fraction of the full Fakeddit
  corpus; results may not hold at the dataset's full scale or on its natural (non-rebalanced) class
  distribution.
- **Non-standard split.** Test numbers above are not directly comparable to papers using Fakeddit's official
  test file, since this project pools and re-splits all three official files (see Methodology).
- **Calibration reduces average overconfidence, not per-example error.** A calibrated confidence of 90% means
  roughly 90% of predictions *at that confidence level* are correct on the test set — it says nothing about
  whether any single prediction is one of the correct ones.
- **Observed high-confidence errors on degenerate/out-of-distribution input.** When this model was reloaded
  from disk and tested (the mandatory save→reload→predict verification step), it predicted **"real" with
  >95% confidence for an empty string and for a 60-character string of repeated "a" characters**, and
  predicted **"fake" with 95% confidence for the plain, unremarkable headline** "Local city council approves
  new budget for public libraries" — while a deliberately sensational headline was predicted "real." This
  is reported here because it happened, not because it was expected: it suggests the calibration fit on
  validation data (which doesn't include degenerate strings) does not extend to genuinely out-of-distribution
  inputs, and that the 79.8% test accuracy should not be read as "79.8% of individual real-world predictions
  are trustworthy" — it is the average, in-distribution, held-out-test-set performance.

## How to use

```python
from transformers import AutoModelForSequenceClassification, AutoTokenizer
import torch, torch.nn.functional as F

model_id = "abhinav-29/fakeddit-bert-fake-news"
model = AutoModelForSequenceClassification.from_pretrained(model_id)
tokenizer = AutoTokenizer.from_pretrained(model_id)

text = "Local city council approves new budget for public libraries"
enc = tokenizer(text, max_length=64, padding="max_length", truncation=True, return_tensors="pt")
with torch.no_grad():
    logits = model(**enc).logits
probs = F.softmax(logits, dim=-1)  # for calibrated confidence, divide logits by the
                                     # temperature in calibration.json before softmax
print(probs)
```
